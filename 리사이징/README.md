# 리사이징 코엑스

PPTX와 이미지의 크기를 조정하고 요소를 편집하는 로컬 웹 편집기 소스입니다.

Node.js가 설치된 환경에서 이 폴더의 `node server.cjs`를 실행하면 기본적으로 `http://127.0.0.1:4174/`에서 편집기를 엽니다. Windows에서는 `시작.cmd`를 사용할 수 있습니다.

사진 분석과 생성 등 일부 기능은 별도의 Python 환경, 모델 파일 또는 서비스 설정이 필요합니다. 이 저장소에는 개인 API 키와 `.local-ai` 로컬 환경, 개인 테스트 파일이 포함되지 않습니다. 유료 API 기능은 별도의 OpenAI API 계정과 설정이 필요합니다. 모델의 실제 인식 및 생성 품질은 입력에 따라 다르므로 결과를 확인해야 합니다.

`dist/vendor`에 포함된 외부 구성요소의 라이선스와 고지 파일을 함께 보존합니다.
